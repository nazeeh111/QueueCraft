# Engine and recording contract v2

All integer fields are checked signed 64-bit. Price is integer ticks, quantity integer lots; money is tick*lot units. Fee rounding is ceiling(notional * fee_ppm / 1,000,000), nonnegative taker fees. Wide intermediate arithmetic for fee and liquidity numerators prevents false overflow before division. No floating point in engine. Python uses arbitrary integers to independently verify C++ bounds. `parse_decimal(text,scale)` uses scale as number of decimal places, 0..18. Unknown exchange timestamp is -1; timestamps from an archive capture are never relabeled as exchange timestamps.

Parser details: final LF mandatory, ASCII decimal integers only, no quoting or leading plus. U may delete an entire side; validity means synchronized state, not available two-sided liquidity. While invalid, U advances validated metadata but cannot recreate synchronized state; only S restores validity. Exchange timestamp monotonicity enforced within contiguous valid state, allowing explicit gap recovery. G is exactly one row with side B, price1, quantity0. S requires both sides. A decision additionally requires both sides. Native validate(text) checks the original bytes before SDK grouping, so Python CSV reserialization cannot conceal malformed input.

Normalized input CSV header: `event,exchange_ns,receive_ns,kind,side,price,quantity`. No quoting/whitespace/extra fields. event IDs contiguous from 0. Each event has identical timestamps/kind on all its rows. receive_ns nondecreasing, exchange_ns nondecreasing within a contiguous session. kind S replaces the entire book atomically; U applies absolute levels atomically, zero deletes; G invalidates the book until a fresh S. side B/A, price>0, quantity>=0. S requires both sides, no zero sizes. Duplicate side/price within one message rejected. Crossed/locked books rejected. Maximum 10,000 levels per side and 20,000 rows/event, 1,000,000 rows/file, 64 MiB/file. A rejected transaction changes no state. Snapshots arriving during a valid book may be treated as an explicit resynchronization. No inference that local IDs prove exchange completeness. All output after a gap is invalid until S.

CLI: `queuecraft-core INPUT.csv OUTPUT_DIRECTORY [buy|sell quantity latency_ns fee_ppm liquidity_ppm --recording-end-ns END]`. Output refuses existing directory, produces books.csv of every complete level after every event (`event,exchange_ns,receive_ns,valid,side,price,quantity`) plus optional fill/ledger for the single immediate order. Generic C++ SDK in include/queuecraft/engine.hpp. Python native extension `queuecraft._native` should expose parse_decimal(str,scale), replay(text) returning complete canonical CSV, and execute(text,side,quantity,latency_ns,fee_ppm,liquidity_ppm,*,recording_end_ns=END) returning fill/ledger CSV or dict. The end is required, keyword-only and an exact signed64 integer. C++ `execute` requires a typed `RecordingBounds{end_ns}` fourth argument. Replay-only reconstruction needs no hypothetical-order bound.

Execution: independent hypothetical trajectory per policy/scenario. Two-side recorded book plus consumed overlay. At each recorded absolute update reconcile modeled consumption conservatively: `consumed_new=min(consumed_old,new_recorded_quantity)` at surviving price, remove on delete; a snapshot preserves consumption at surviving prices too. Thus no repeated use unless modeled consumption is eliminated by observed depletion/removal; never imply true replenishment identity. Alternative replenishment assumption is scenario-only and must be explicit. Availability floor((recorded-consumed)*liquidity_ppm/1e6). Fill eligible opposite levels in price priority, partial fills supported. No passive orders. Zero liquidity cannot fill. Limit total requested lots <= declared small-order cap in wrapper. Cash starts at 0 as a signed delta account with inventory 0; buy cash -= notional+fee, sell cash += notional-fee, inventory += signed quantity. Check every multiplication/addition, do not partially mutate on overflow.

Hypothetical IOC orders have decision observation time, arrival=observation+latency, ack=arrival+latency. Recorded events at time t are applied before arrivals at t (adverse alternative explicit scenario if implemented). Do not resolve ties using future fills. Immediate order observes first valid book and arrives later; all recorded events <=arrival apply first. If arrival exceeds the independently declared recording end, no fill occurs and remaining intent is recorded. A quiet but covered prefix remains eligible until its declared end, subject to staleness. Decisions use only receive-time prefixes. Full strategy scheduler lives in Python over native Book/execute primitive if needed. A slow Python reference must implement all book/ledger transitions independently.

Common prospective-study benchmark: recorded midpoint at parent start, held outside policy observations, represented as twice-mid ticks (bid+ask), signed implementation shortfall = side_sign*(2*notional - filled*benchmark2)/2 + fees + unfilled*penalty_ticks. Exact twice-money numerator retained. Policies must share parent order, cap, observation schedule, fees and remaining penalty. Deadline action must arrive by deadline. No future market price used to value remaining intent.

Revision: recorder-terminal metadata is now mandatory in `run`. It is not
inferred from the final future payload. Explicit recorder bounds constrain
callbacks/fills and are persisted in Simulation/configuration and checked by
SQL. A held recording horizon with a shorter/sparser event prefix must preserve
all earlier decisions, fills, ledger transitions and acknowledgements. An input
event outside declared recording coverage is an error. The acquisition bound
is a supplied declaration, not proof of exchange continuity.

`benchmark2`, when explicitly supplied to `run`, is an evaluation-only common
reference. It never appears in Observation/Intent and cannot influence strategy
decisions. A new versioned export schema2 records coverage. The old schema and
historical study plan require their pinned original source; current code refuses
to silently reinterpret them.
